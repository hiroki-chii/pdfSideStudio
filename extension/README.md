# PDF Side Studio

ChromeのサイドパネルでPDFを編集するManifest V3拡張機能です。PDFは端末内で処理します。外部送信、アクセス解析、外部CDN、アカウント登録はありません。

## インストール

1. このプロジェクトの `dist` フォルダーを用意します。配布ZIPの場合は `release/pdf-side-studio.zip` を任意のフォルダーに展開してください。
2. Chromeのアドレス欄に `chrome://extensions` を入力します。
3. 右上の「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」から `dist`（ZIPの場合は展開先）を選択します。
5. ツールバーの拡張機能一覧から「PDF Side Studio」をクリックすると、サイドパネルが開きます。ピン留めすると便利です。

Chrome 120以降を対象にしています。最新版を推奨します。読み込み後にフォルダーを移動・削除しないでください。Chrome Web Storeへの公開・署名済みCRX化は含みません。

## 機能と使い方

PDFを読み込むと、初期状態では「選択」モードになります。プレビュー上部に「選択・ペン・テキスト・回転・透かし」を名前付きで常設し、選択中の機能をボタンの色で示します。アイコンにしばらくカーソルを合わせると、ブラウザー標準のツールチップで操作説明を表示します。表示までの時間はブラウザーの標準動作に従います。設定欄の高さは280pxで統一し、切り替えによる紙面の移動を防ぎます。同じツールの再クリックではモードを解除せず、終了ボタン・「選択」・Escで選択モードに戻ります。ツール切り替え時の対象は、回転が「表示中のページ」、透かしが「すべてのページ」になります。プレビューの矢印ボタン・左右キーでページを移動しても、選択中の機能と対象設定を維持します。配置済みの透かしをクリックして選択した場合は、そのページを対象にします。

| 機能 | 操作 |
| --- | --- |
| 表示モード | 上部のアイコンをクリックするたびに、月（ダーク）→太陽（ライト）→PC（デバイスと同じ）の順で切り替え。選択を端末に保存 |
| 保存設定 | 右下の小さな「保存」ボタンで最前面のダイアログを開き、ファイル名を指定して「PDFを保存」または「1ページずつ分割（ZIP）」。閉じるボタン・Escで編集画面に戻る |
| プレビューのページ移動 | プレビュー左右の矢印をクリック、またはテキストボックス・描画を選択していない状態でキーボードの ← / →。選択中の機能・設定を維持し、入力中のテキストは移動前のページに確定。先頭・末尾では矢印を無効化 |
| 結合 | PDFを複数追加し「PDFを保存」。追加順・ページ一覧の順に結合 |
| 追加元の識別 | 追加したPDFごとに番号と色を割り当て、ページ一覧のサムネイルとファイル名一覧に表示。並べ替えやコピー後も追加元を確認可能 |
| 分割 | 保存画面で「1ページずつ分割（ZIP）」を押し、全ページを個別のPDFとしてZIPに保存 |
| 回転 | 「回転」で設定を開き、対象を「表示中のページ／すべてのページ」から指定。ページ番号・対象ページ数を確認し、方向ボタンで左右90度ずつ回転。全ページ指定時は実行ボタンにも対象ページ数を表示 |
| ペン・マーカー | 「ペン」で設定を開き、色・太さ・透明度を選び紙面をドラッグ。太さは1〜40pt、透明度は0〜95%。「描画を終了」・「選択」・Escで終了。描画中は既存の文字・描画を選択せず、上に重ねて描けます |
| 直線・丸・四角 | ペン設定の「描く形」を変更してドラッグ。丸は楕円、四角は長方形。Shiftを押しながらドラッグすると正円・正方形 |
| 描画の選択・移動・削除 | 選択モードでペンの線・直線・丸・四角をクリック。「選択した描画」専用の操作欄を表示。ドラッグや方向キーで1pt、Shift＋方向キーで10pt移動。Deleteまたは削除ボタンで個別に削除。「新しく描く」で描画モードへ。Esc・空白クリック・「選択を解除」で解除。移動・削除はUndo／RedoとPDF保存に対応 |
| テキスト挿入・移動 | 「テキスト」→紙面クリックで1つ配置し、日本語・改行を直接入力。「入力を確定」・外側クリック・Ctrl+Enterで確定して選択モードへ。「入力を取り消す」は新規ボックスを残さず、再編集なら元の内容へ戻します。新規入力中のEscは確定、再編集中のEscは変更取消。確定後はそのまま方向キー・Deleteで操作可能。空欄の新規ボックスは残しません。選択した文字の色・サイズ（8〜96pt）は即時反映。ドラッグで移動、ダブルクリック・「内容を編集」・選択枠でEnterを押すと再編集。方向キーで1pt、Shift＋方向キーで10pt移動、Deleteまたは削除ボタンで削除。文字入力中の方向キー・Deleteは文字の編集に使用。追加・移動・書式変更・削除はUndo／Redoに対応 |
| ウォーターマーク | 「透かし」で設定を開き、テキスト・色・濃さ・対象を指定。対象ページ番号／全ページ数と追加済み透かし件数を確認し「適用」で反映。追加済み透かしを置き換えます。空欄では適用不可、対象に追加済み透かしがない場合は削除不可。削除対象も同じページ指定を使用。元PDFの透かしは削除不可。「選択に戻る」・「選択」・Escで終了 |
| 並べ替え | プレビューの外側・上部に常時表示するページ一覧のサムネイルをドラッグし、紫の挿入線の位置にドロップ |
| コピー・削除 | ページ一覧の各サムネイルにカーソルを合わせると、上部にコピー・削除アイコンを表示。アイコンを押した1ページに適用。コピーは元ページの直後に追加して表示し、削除後は次のページ（末尾なら前のページ）を表示。「元に戻す」で復元可能。Tabでフォーカスしたときもアイコンを表示 |
| Undo / Redo | プレビュー枠の右上にある「元に戻す」「やり直す」ボタン。編集履歴のキーボードショートカットは無効 |

透明度0%は不透明で、数値を上げるほど下の文字が透けます。マーカーには透明度70%・太さ20〜30ptが目安です。色・太さ・透明度・形の変更は、次に描く書き込みから適用されます。直線・丸・四角・テキストの挿入／移動／更新／削除もUndo／RedoとPDF保存に対応します。ペン設定の「このページの描画をまとめて消去」を開くと一括消去ボタンが現れ、テキストを残してペン・図形だけを消去します。

ページ一覧のサムネイルをクリックするとプレビューが切り替わります。コピー・削除はホバー時に表示する上部のアイコンから操作します。ドラッグ中はアイコンを隠します。ドラッグではつかんだ1ページを移動し、表示中のページは維持します。ページ一覧の左右端にドラッグすると自動スクロールします。並べ替えもUndo／Redoに対応し、一覧の順序で保存します。ペンは表示中のページに適用します。ペンの太さはPDFポイント単位です。保存ダイアログの「PDFを保存」は全ページを1つのPDFに、「1ページずつ分割（ZIP）」は全ページを個別のPDFにして保存します。Ctrl+Sでも保存設定を開けます。

元のPDFファイルは変更しません。編集中の内容はメモリー内だけにあり、パネルを閉じる・再読み込みする・Chromeを終了する前に保存してください。ダウンロード先はChromeの設定に従います。

表示モードの初期値は「デバイスと同じ」です。デバイスの配色設定が変わると自動で追従します。ライト／ダークを選ぶとその配色に固定します。モードは次回の起動時も復元します。PDFの紙面・書き込み・透かし・保存結果の色は表示モードによって変わりません。

## 制限

- パスワード保護PDF、暗号化PDFは非対応です。
- 1ファイル50MiB、読み込み累計150MiB、編集対象300ページまで。履歴は直近30操作です。取り消した追加分も読み込み累計に含まれます。
- 通常のページ内容をコピーして編集します。フォーム、既存の注釈、リンク、しおり、添付ファイル、タグ等の完全な保持は保証しません。電子署名は維持できません。
- 元の文字や画像の再編集、OCR、既存の透かしの削除、機密情報の墨消し機能はありません。
- ペン・図形・挿入テキスト・透かしは透過PNGとしてPDFに埋め込みます。元ページのテキストや図形は画像化しません。追加テキストは保存したPDF内では検索・選択できません。挿入テキストの再編集・移動は保存前のこのパネル内で行えます。
- 大きな用紙では追加画像の長辺を4096pxに制限します。文字表示は端末にある日本語フォントに依存します。
- 透かしはページ中央に斜めで表示します。回転後も画面基準の斜め向きを保ち、保存結果はプレビューに一致します。ペンは紙面に固定して一緒に回転します。
- 非常に複雑なPDFではメモリー不足やプレビュー失敗が起こり得ます。保存後のPDFを確認してください。

## 開発

Node.js 22.12以降（24推奨）が必要です。

```powershell
npm ci
npm run check
npm test
npm run build
```

ビルド成果物は `dist/`、配布用ZIPは `release/pdf-side-studio.zip` です。`npm run dev` で通常のブラウザー上でも画面を確認できます。PDF.jsの日本語CMap等は配布ビルドにコピーされるため、実ファイルを使う確認はビルド後の `npx vite preview --host 127.0.0.1` を推奨します。Chromeのサイドパネル起動は、拡張機能として読み込んだ状態で確認してください。

権限は `sidePanel` のみです。閲覧中のタブを読む権限や、サイトへのアクセス権限は要求しません。PDF.jsのworker・CMap・標準フォント・画像デコーダーは同梱します。ライセンスはビルド内 `THIRD_PARTY_LICENSES.txt` を参照してください。

## 今後追加すると便利な機能

1. セッションの自動保存と復元：パネルを閉じても編集途中から再開。
2. ページ番号・日付・定型スタンプ：配布資料作成の手間を軽減。
3. 画像をPDFに変換：写真やスキャン画像も結合対象に。
4. OCRによる文字検索：画像だけのPDFを検索可能に。
5. 画像の再圧縮：画質とサイズを比較しながら容量削減。
