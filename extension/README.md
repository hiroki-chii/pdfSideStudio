# PDF Side Studio

ChromeのサイドパネルでPDFを編集するManifest V3拡張機能です。PDFは端末内で処理します。外部送信、アクセス解析、外部CDN、アカウント登録はありません。

## インストール

1. このプロジェクトの `dist` フォルダーを用意します。配布ZIPの場合は `release/pdf-side-studio.zip` を任意のフォルダーに展開してください。
2. Chromeのアドレス欄に `chrome://extensions` を入力します。
3. 右上の「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」から `dist`（ZIPの場合は展開先）を選択します。
5. ツールバーの拡張機能一覧から「PDF Side Studio」をクリックすると、サイドパネルが開きます。ピン留めすると便利です。

Chrome 120以降を対象にしています。最新版を推奨します。読み込み後にフォルダーを移動・削除しないでください。Chrome Web Storeへの公開・署名済みCRX化は含みません。

## 機能と使い方

PDFを読み込むと、初期状態では「選択」モードになります。プレビュー上部に「選択・ペン・テキスト・回転・透かし」を名前付きで常設し、選択中の機能をボタンの色で示します。アイコンにしばらくカーソルを合わせると、ブラウザー標準のツールチップで操作説明を表示します。表示までの時間はブラウザーの標準動作に従います。メニューはアイコンをクリックするとプレビューの上に重なって表示され、同じアイコンの再クリックまたはメニュー外のクリックで閉じます。開閉しても紙面の位置と高さは変わらず、長いメニューは内部でスクロールできます。メニューを閉じても描画モードや入力中の文字は保持し、終了ボタン・「選択」・Escで選択モードに戻ります。ツール切り替え時の対象は、回転が「表示中のページ」、透かしが「すべてのページ」になります。プレビューの矢印ボタン・左右キーでページを移動しても、選択中の機能と対象設定を維持します。配置済みの透かしをクリックして選択した場合は、そのページを対象にします。

| 機能 | 操作 |
| --- | --- |
| 表示モード | 上部のアイコンをクリックするたびに、月（ダーク）→太陽（ライト）→PC（デバイスと同じ）の順で切り替え。選択を端末に保存 |
| 保存設定 | 右下の小さな「保存」ボタンで最前面のダイアログを開き、ファイル名を指定して「PDFを保存」または「1ページずつ分割（ZIP）」。閉じるボタン・Escで編集画面に戻る |
| プレビューのページ移動 | プレビュー左右の矢印をクリック、またはテキストボックス・描画を選択していない状態でキーボードの ← / →。選択中の機能・設定を維持し、入力中のテキストは移動前のページに確定。先頭・末尾では矢印を無効化 |
| プレビューの拡大・縮小 | プレビュー左下の「−」「＋」、またはプレビュー内でCtrl＋マウスホイール（上で拡大、下で縮小）により50〜400%を25%ずつ調整。「全体表示」で紙面全体が収まる100%に戻る。通常のホイール操作ではスクロール。ページを切り替えても倍率を維持し、保存・印刷の用紙サイズには影響しません |
| 全画面プレビュー | 左下の倍率操作の右端にある四隅のアイコンから、表示中のページをサイドパネル全体に一時表示。書き込み・透かしも表示し、右上の「×」またはEscで閉じます。下部の矢印と「現在のページ／全ページ数」でページ移動でき、倍率は維持します。左右キーでも移動できますが、紙面のスクロール領域にフォーカスがあり横スクロール可能な場合は紙面をスクロールします。「−」「＋」・Ctrl＋ホイールで拡大・縮小できます。入力中のテキストは開く前に確定し、閉じると編集画面の元のページ・倍率・スクロール位置を保って戻ります |
| 結合 | PDFを複数追加し「PDFを保存」。追加順・ページ一覧の順に結合 |
| 追加元の識別 | 追加したPDFごとに番号と色を割り当て、ページ一覧のサムネイルとファイル名一覧に表示。並べ替えやコピー後も追加元を確認可能 |
| 分割 | 保存画面で「1ページずつ分割（ZIP）」を押し、全ページを個別のPDFとしてZIPに保存 |
| 回転 | 「回転」で設定を開き、対象を「表示中のページ／すべてのページ」から指定。ページ番号・対象ページ数を確認し、方向ボタンで左右90度ずつ回転。全ページ指定時は実行ボタンにも対象ページ数を表示 |
| ペン・マーカー | 「ペン」で設定を開き、色・太さ・透明度を選び紙面をドラッグ。太さは1〜40pt、透明度は0〜95%。Ctrl＋↑／↓で太さを1ptずつ増減、Ctrl＋←／→で透明度を1%ずつ下げる／上げる。「描画を終了」・「選択」・Escで終了。描画中は既存の文字・描画を選択せず、上に重ねて描けます |
| 直線・丸・四角 | ペン設定の「描く形」を変更してドラッグ。丸は楕円、四角は長方形。Shiftを押しながらドラッグすると正円・正方形 |
| 描画の選択・書式変更・移動・削除 | 選択モードでペンの線・直線・丸・四角をクリック。Shift＋クリック（Ctrl／Command＋クリックも可）で追加選択・解除。「ペン」ボタンで設定を開閉し、色・太さ・透明度を選択した描画に即時反映。複数選択時の太さ・透明度は相対変更。選択中はほかの編集ツールを無効化。ドラッグや方向キーでまとめて1pt、Shift＋方向キーで10pt移動。Deleteまたは削除ボタンでまとめて削除。「新しく描く」で描画モードへ。Esc・空白クリック・「選択を解除」で全選択を解除。書式変更・移動・削除はUndo／RedoとPDF保存に対応 |
| テキスト挿入・移動 | 「テキスト」→紙面クリックで1つ配置し、日本語・改行を直接入力。「入力を確定」・外側クリック・Ctrl+Enter・Escで確定して選択モードへ。既存テキストの再編集でもEscは編集内容を保持し、そのまま移動できます。「入力を取り消す」は新規ボックスを残さず、再編集なら元の内容へ戻します。確定後はそのまま方向キー・Deleteで操作可能。空欄の新規ボックスは残しません。選択した文字の色・サイズ（8〜96pt）は即時反映。ドラッグで移動、クリック・「内容を編集」・選択枠でEnterを押すと再編集。方向キーで1pt、Shift＋方向キーで10pt移動、Deleteまたは削除ボタンで削除。文字入力中の方向キー・Deleteは文字の編集に使用。追加・移動・書式変更・削除はUndo／Redoに対応 |
| ウォーターマーク | 「透かし」で設定を開き、テキスト・色・濃さ・対象を指定。対象ページ番号／全ページ数と追加済み透かし件数を確認し「適用」で反映。追加済み透かしを置き換えます。空欄では適用不可、対象に追加済み透かしがない場合は削除不可。削除対象も同じページ指定を使用。元PDFの透かしは削除不可。「選択に戻る」・「選択」・Escで終了 |
| 並べ替え | プレビューの外側・上部に常時表示するページ一覧のサムネイルをドラッグし、紫の挿入線の位置にドロップ |
| コピー・削除 | ページ一覧の各サムネイルにカーソルを合わせると、上部にコピー・削除アイコンを表示。アイコンを押した1ページに適用。コピーは元ページの直後に追加して表示し、削除後は次のページ（末尾なら前のページ）を表示。「元に戻す」で復元可能。Tabでフォーカスしたときもアイコンを表示 |
| Undo / Redo | プレビュー枠の右上にある「元に戻す」「やり直す」ボタン。編集履歴のキーボードショートカットは無効 |

透明度0%は不透明で、数値を上げるほど下の文字が透けます。マーカーには透明度70%・太さ20〜30ptが目安です。描画を選択中は色・太さ・透明度をその描画に適用します。「ペン」への切り替えや「新しく描く」で描画モードを開始すると、太さ3pt・透明度0%のデフォルトに戻ります。その後に変更した設定は同じ描画モードで次に描く線・図形に適用され、設定メニューの開閉では保持します。「描く形」は新規描画時だけ変更できます。直線・丸・四角・テキストの挿入／移動／更新／削除もUndo／RedoとPDF保存に対応します。描画の削除は対象をクリック・Shift＋クリックで選択し、Deleteまたは「選択した描画を削除」で行います。

ペンのショートカットは、描画を選択中なら選択した描画を変更し、描画モードなら次に描く線・図形の設定を変更します。設定メニューが閉じていても使えます。複数選択では、太さ・透明度を各描画の元の値から同じ量だけ増減します。例えば太さ3ptと8ptを選んでCtrl＋↑を押すと4ptと9ptになります。スライダーも操作開始時の各描画の値を基準に同じ差分を適用し、表示値は最後に選んだ描画の値です。1つでも上限・下限（太さ1〜40pt、透明度0〜95%）に達したら、同じ方向への変更を選択全体で止めて差を保ちます。例えば38ptと40ptはそれ以上太くならず、反対方向への変更は続けられます。スライダーを大きく動かしても全体が最初の境界で止まり、表示値も実際の値に合わせます。色は選択全体を同じ色に変更します。書式変更・移動・削除は1操作をまとめてUndo／Redoでき、境界で変化がなければ履歴を作りません。入力欄の操作中・IME変換中・ドラッグ中はショートカットを適用しません。テキストの選択・編集中のCtrl＋↑／↓は、従来どおり文字サイズを変更します。

ページ一覧のサムネイルをクリックするとプレビューが切り替わります。コピー・削除はホバー時に表示する上部のアイコンから操作します。ドラッグ中はアイコンを隠します。ドラッグではつかんだ1ページを移動し、表示中のページは維持します。ページ一覧の左右端にドラッグすると自動スクロールします。並べ替えもUndo／Redoに対応し、一覧の順序で保存します。ペンは表示中のページに適用します。ペンの太さはPDFポイント単位です。保存ダイアログの「PDFを保存」は全ページを1つのPDFに、「1ページずつ分割（ZIP）」は全ページを個別のPDFにして保存します。Ctrl+Sでも保存設定を開けます。

描画を選択してCtrl＋Shift＋↑／↓を押すと、中心を基準に縦横比を保って拡大／縮小します。↑は1.1倍、↓は1.1分の1で、複数選択では描画同士の形と配置の比率を保って全体を変更します。線の太さ・色・透明度は保持します。紙面端では選択全体の拡大を止め、縮小は線の軌跡の長辺1ptまでです。点1つだけの描画は大きさを変更しません。1操作ごとにUndo／Redoでき、境界で変更がなければ履歴を作りません。

元のPDFファイルは変更しません。編集中の内容はメモリー内だけにあり、パネルを閉じる・再読み込みする・Chromeを終了する前に保存してください。ダウンロード先はChromeの設定に従います。

表示モードの初期値は「デバイスと同じ」です。デバイスの配色設定が変わると自動で追従します。ライト／ダークを選ぶとその配色に固定します。モードは次回の起動時も復元します。PDFの紙面・書き込み・透かし・保存結果の色は表示モードによって変わりません。

テキストの書式は「テキスト」メニューまたはショートカットで設定できます。色・サイズに加え、フォント（ゴシック／明朝／等幅）、太字・斜体・下線、左揃え・中央揃え・右揃えに対応します。編集モードでは選択した文字だけに書式を適用し、配置は選択した行に適用します。文字を選択していない場合は書式を変更せず、選択を促します。選択モードではボックス全体に適用します。中央・右揃えは最長行の幅を基準に短い行を揃えます。部分書式はEscでの確定・移動・再編集・PDF保存・印刷でも保持します。

テキストはShift＋クリック（Ctrl／Command＋クリックも可）で追加選択・解除でき、選択した複数のボックスに書式を一括適用できます。文字サイズ欄とCtrl＋↑／↓は各ボックスのサイズ差を保って増減し、部分書式の文字サイズも含めて、1つでも下限8pt・上限96ptに達すると同じ方向への変更を全体で止めます。例えば24ptと36ptを選んで1pt増やすと25ptと37ptになります。サイズ欄には最後に選んだテキストの先頭文字の値を表示し、大きな数値変更も最初の境界で止めます。逆方向への変更は可能です。サイズ以外の書式は選択全体に同じ設定を適用します。

複数選択したテキストはドラッグ・方向キーでまとめて移動、Deleteでまとめて削除できます。選択中のボックスをクリックしても複数選択を保持し、ダブルクリックするとそのボックスだけを編集します。「内容を編集」とF2は単独選択時に使えます。Esc・空白クリック・「選択を解除」でまとめて解除します。一括の書式変更・移動・削除は1操作としてUndo／Redoできます。どれかのテキストが紙面に収まらない書式変更は選択全体を変更せず、エラーを表示します。

| テキストのショートカット | 操作 |
| --- | --- |
| F2 | 選択したテキストボックスの内容編集を開始 |
| Ctrl+B | 太字を切り替え |
| Ctrl+I | 斜体を切り替え |
| Ctrl+U | 下線を切り替え |
| Ctrl+↑ / Ctrl+↓ | 文字サイズを1ptずつ拡大／縮小（8〜96pt） |

配置済みテキストをクリックすると、メニューを閉じたまま内容を編集できます。上部の「テキスト」アイコンで、文字の選択範囲や入力途中の内容を保持したまま書式欄を開閉します。選択・入力中はほかの編集ツール（選択・ペン・回転・透かし）をグレーアウトします。Escで編集を確定すると、ボックスを選択した状態で移動や全体の書式変更ができます。さらにEscを押すか空白をクリックすると選択を解除します。書式変更はUndo／Redoに対応し、フォントは端末内のものを使用します。

テキスト・描画の選択は、紙面内の空白に加え、資料の周囲や画面の余白をクリックしても解除できます。入力中のテキストは確定してから解除します。書式メニュー・操作ボタン・入力欄の操作では選択を解除しません。

## 制限

- パスワード保護PDF、暗号化PDFは非対応です。
- 1ファイル50MiB、読み込み累計150MiB、編集対象300ページまで。履歴は直近30操作です。取り消した追加分も読み込み累計に含まれます。
- 通常のページ内容をコピーして編集します。フォーム、既存の注釈、リンク、しおり、添付ファイル、タグ等の完全な保持は保証しません。電子署名は維持できません。
- 元の文字や画像の再編集、OCR、既存の透かしの削除、機密情報の墨消し機能はありません。
- ペン・図形・挿入テキスト・透かしは透過PNGとしてPDFに埋め込みます。元ページのテキストや図形は画像化しません。追加テキストは保存したPDF内では検索・選択できません。挿入テキストの再編集・移動は保存前のこのパネル内で行えます。
- 大きな用紙では追加画像の長辺を4096pxに制限します。文字表示は端末にある日本語フォントに依存します。
- 透かしはページ中央に斜めで表示します。回転後も画面基準の斜め向きを保ち、保存結果はプレビューに一致します。ペンは紙面に固定して一緒に回転します。
- 非常に複雑なPDFではメモリー不足やプレビュー失敗が起こり得ます。保存後のPDFを確認してください。

## 開発

Node.js 22.12以降（24推奨）が必要です。

```powershell
npm ci
npm run check
npm test
npm run build
```

ビルド成果物は `dist/`、配布用ZIPは `release/pdf-side-studio.zip` です。`npm run dev` で通常のブラウザー上でも画面を確認できます。PDF.jsの日本語CMap等は配布ビルドにコピーされるため、実ファイルを使う確認はビルド後の `npx vite preview --host 127.0.0.1` を推奨します。Chromeのサイドパネル起動は、拡張機能として読み込んだ状態で確認してください。

権限は `sidePanel` のみです。閲覧中のタブを読む権限や、サイトへのアクセス権限は要求しません。PDF.jsのworker・CMap・標準フォント・画像デコーダーは同梱します。ライセンスはビルド内 `THIRD_PARTY_LICENSES.txt` を参照してください。

## 今後追加すると便利な機能

1. セッションの自動保存と復元：パネルを閉じても編集途中から再開。
2. ページ番号・日付・定型スタンプ：配布資料作成の手間を軽減。
3. 画像をPDFに変換：写真やスキャン画像も結合対象に。
4. OCRによる文字検索：画像だけのPDFを検索可能に。
5. 画像の再圧縮：画質とサイズを比較しながら容量削減。
