# Chrome Web Store 掲載用スクリーンショット

作成日: 2026-10-04

すべて1280×800ピクセルのJPEGです。Chrome Web Storeの「スクリーンショット」欄に画像ファイルを個別にアップロードしてください。

| ファイル | 内容 |
| --- | --- |
| 01-start.jpg | 開始画面と端末内処理の案内 |
| 02-pages.jpg | 2つのPDFの読み込み、3ページの一覧と編集ツール |
| 03-text.jpg | 日本語テキストの追加と編集設定 |
| 04-watermark.jpg | 全3ページへのDRAFT透かしの適用 |
| 05-save-split.jpg | PDF保存と1ページずつ分割する設定 |

既存の配布ビルド（dist）をローカルのプレビューサーバーで開いて撮影しました。Chromeのサイドパネル自体の撮影ではありません。既存のサンプルPDFを使い、追加した文字と透かしはアプリの通常操作で配置しています。

画像のデコード、JPEG形式、1280×800の寸法、5枚の存在を確認済みです。掲載用の440×280の小さいプロモーション画像はこのセットに含みません。
